# BIM Portal - Детальный План Проекта

## 🎯 Обзор проекта (для спонсоров)

**BIM Portal** - это профессиональная биржа фрилансеров в нише BIM-проектирования. Платформа соединяет заказчиков, которым нужны BIM-специалисты, с квалифицированными фрилансерами для реализации проектов в строительстве и архитектуре.

### 💰 Монетизация
- **Подписки заказчиков**: PRO - 2,900₽/мес (20 вакансий), Premium - 7,900₽/мес (безлимит)
- **Платная публикация вакансий**: 1,500₽ за разовую публикацию
- **Комиссия с контрактов**: 10% от суммы сделки

### 🎯 Целевая аудитория
- **Заказчики**: строительные компании, архитектурные бюро, девелоперы
- **Фрилансеры**: BIM-моделлеры, архитекторы, инженеры-проектировщики

## 📊 Технологический стек

### Frontend:
- **Next.js 14** с App Router
- **TypeScript** для типизации
- **Tailwind CSS** для стилей
- **shadcn/ui** для компонентов
- **Framer Motion** для анимаций

### Backend:
- **tRPC v11** для API
- **Prisma** для ORM
- **PostgreSQL** (Supabase) для БД
- **Zod** для валидации

### Интеграции:
- **Clerk** - авторизация
- **ЮKassa** - платежи
- **Stream Chat** - мессенджер
- **Resend** - email
- **Telegram Bot** - уведомления
- **Cloudflare R2** - файлы

### Деплой:
- **Vercel** - хостинг
- **GitHub Actions** - CI/CD

# BIM Portal

Профессиональная биржа фрилансеров в нише BIM-проектирования. Платформа соединяет заказчиков, которым нужны BIM-специалисты, с квалифицированными фрилансерами для реализации проектов в строительстве и архитектуре.

## 🎯 Обзор проекта

**BIM Portal** - это современная веб-платформа для поиска и найма BIM-специалистов. Проект построен на стеке Next.js 16.2.2 с TypeScript, использует Supabase для базы данных и Clerk для авторизации.

### 💰 Монетизация
- **Подписки заказчиков**: PRO - 2,900₽/мес (20 вакансий), Premium - 7,900₽/мес (безлимит)
- **Платная публикация вакансий**: 1,500₽ за разовую публикацию
- **Комиссия с контрактов**: 10% от суммы сделки

### 🎯 Целевая аудитория
- **Заказчики**: строительные компании, архитектурные бюро, девелоперы
- **Фрилансеры**: BIM-моделлеры, архитекторы, инженеры-проектировщики

---

## 🚀 Технологический стек

### Frontend
- **Next.js 16.2.2** - React-фреймворк с App Router
- **TypeScript** - типизация JavaScript
- **Tailwind CSS** - CSS-фреймворк для стилизации
- **Clerk** - система аутентификации

### Backend & Database
- **Supabase** - PostgreSQL база данных с API
- **Prisma** - ORM для работы с базой данных
- **tRPC** - типизированный API
- **Next.js API Routes** - REST API эндпоинты

### Инфраструктура
- **Git** - система контроля версий
- **ESLint & Prettier** - линтинг и форматирование кода
- **Vercel** - хостинг (планируется)
